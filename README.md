# Create: Soul Harvest

Create: Soul Harvest is a Create addon that adds, primarily, a means of obtaining mob drops and experience without actually spawning entities.
The 'souls' of mobs can be stored in appropriate **Soul Books**, which can then be used to **attune** various forms of precursor material such as **Polyclay** and **Experience Effigies**.
Once **Attuned**, they can then be processed to extract the loot of the mob whose 'soul' it is attuned to.

Inspired by Woot's entity-free grinding logic.
